# V1 Scope — Personal Cognition Ledger

## Included

- Session lifecycle (create, start, stop)
- Task assignment to session
- EvidenceItem (basic types: note, link, file)
- Basic retrieval APIs

---

## Explicitly Excluded

- Replay UI
- Annotation system
- AI features
- Background automation
- Analytics
- Fancy frontend

---

## Rule

If it is not listed in "Included", do not build it.
